# CLAUDE.md — secciones-nacionalidades

## Overview
Interactive R/Shiny web application that visualizes demographic data of nationalities by census section in Spain, using public data from the Instituto Nacional de Estadistica (INE). Covers the period 2012-2021.

## Tech Stack
- R / Shiny
- Docker (image: `drumsergio/secciones-nacionalidades`)
- testthat for testing
- Kubernetes manifests available in `k8s/`

## Development
```bash
# Run locally with R
Rscript -e "shiny::runApp('.', port=3838)"

# Run via Docker
docker run -p 3838:8080 drumsergio/secciones-nacionalidades
```

Tests:
```bash
Rscript -e "testthat::test_dir('tests')"
```

## Architecture
- `global.R` — shared data loading and initialization
- `ui.R` — Shiny UI definition
- `server.R` — server logic and data processing
- `datos_csv/` — raw CSV data files
- `seccionado/` — census section shapefiles
- `poblacion/` — population data
- `R/` — helper R functions
- `k8s/` — Kubernetes deployment manifests
- `docker-compose/` — Docker Compose configurations

## Key Rules
- Data is archived (2012-2021 only); INE stopped publishing this granularity from 2022
- Docker images use semver tags, never `:latest`
- License is GPL-3.0
- All text in the app is in Spanish
